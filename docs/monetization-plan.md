## 1. 제품 현황 진단

현재 Dayflow는 **"개인 일상 운영 올인원"** 포지션. 코드베이스 기준 보유 기능 4축:

| 축 | 기능 | 비고 |
|---|---|---|
| 가계부 (머니) | 거래 기록(ledger/txns), 영수증 업로드, 구독 관리(subs), 머니플로우 | 결제 의향 검증된 카테고리 |
| 일정·생산성 | 캘린더, 메모, 스티키노트, 체크리스트, 타이머 3종 | 대체재 강함 (구글캘린더·노션) |
| 금융 유틸리티 | 연봉 계산기, 대출 검색 | 비로그인 SEO 유입구 + 제휴 수익 후보 |
| 범용 유틸리티 | 이미지 크롭, PDF 편집 | 비로그인 트래픽 유입구 |

기반: Supabase 인증 + RLS, mock/supabase 전환 가능한 3-tier 데이터 레이어, PC/모바일 분리 UI,
모바일 `UpgradeSheet.tsx`에 **Dayflow Pro 시안 완비** (₩3,900/월 · ₩39,000/년 · 3일 무료 체험).

- **강점**: 유입(무료 도구) → 정착(가계부·일정) → 과금(Pro) 퍼널의 뼈대가 이미 코드에 존재.
- **약점**: 축이 4개라 "무엇의 앱인지" 흐릿함. 수익화 전에 핵심 축 하나를 리텐션 엔진으로 세워야 함.

### 핵심 제언 — 가계부(머니) 축을 메인으로

일정·메모는 대체재가 너무 강하지만, "구독 관리 + 영수증 + 머니플로우"는 한국 시장에서
결제 의향이 검증된 카테고리(뱅크샐러드·편한가계부 등). 타이머·메모·캘린더는
**"머니 앱에 딸려오는 보너스"**로 포지셔닝하고 유지보수만, 신규 투자는 머니 축에 집중한다.

## 2. 추가 기능 로드맵

### Phase A — 과금 근거 만들기 (1~2개월, 기존 데이터 레이어로 구현 가능)

| 우선순위 | 기능 | 내용 | 구현 난이도 |
|:---:|---|---|---|
| ★★★ | 예산 설정 | 카테고리별 월 예산 + 초과 경고, MoneyFlow에 진행률 표시 | 하 — 도메인 1개 추가 (기존 8개 도메인 패턴 그대로) |
| ★★★ | 반복 거래 | 월세·구독료 자동 기입. 구독 도메인 ↔ 거래 도메인 연결 | 하 |
| ★★★ | 구독 결제일 알림 | 결제 D-3/D-day 알림. subscriptions 도메인에 결제일 이미 존재 | 중 — 웹푸시 or 이메일 (Supabase Edge Function + cron) |
| ★★ | 월간 리포트 | 카테고리별 지출 요약·전월 대비·구독 합계. UpgradeSheet에 이미 "월간 PDF 리포트"로 약속됨 | 하 — transactions 집계 + RSC 페이지, PDF는 기존 pdf 도구 코드 재활용 |
| ★★ | 영수증 OCR | 업로드 영수증에서 금액·상호 자동 추출. `ReceiptUploadModal` 이미 존재 → UX 변경 최소 | 중 — Edge Function + 외부 OCR/LLM API. **Pro 전용 1순위 후보** |

### Phase B — 리텐션 엔진 (3~5개월)

| 우선순위 | 기능 | 내용 |
|:---:|---|---|
| ★★ | 주간 인사이트 푸시 | "이번 주 외식비가 평소보다 40% 많아요" — daily-log 도메인 활용. 가계부 리텐션의 핵심은 기록 알림이 아니라 **인사이트 알림** |
| ★★ | 데이터 내보내기/가져오기 | CSV·엑셀. 전환장벽 제거(타 가계부에서 이사 오기) + Pro 잠금 포인트(내보내기 무료, 자동 백업 Pro) |
| ★★ | 홈 모듈 커스터마이징 | 홈 6개 모듈(StickyNotes/Checklist/MoneyFlow 등) 켜고 끄고 배치 — preferences 스토어에 유사 토글(`showCalendar`) 기존재. Pro 시안의 "테마·위젯 잠금 해제"와 연결 |
| ★ | 공유 가계부 (커플·룸메이트) | RLS 구조상 `household_id` 도입으로 확장 가능. 결제 전환률 높은 기능이나 스키마 영향 커서 B 후반 |

### Phase C — 확장 (6개월+, PMF 확인 후)

| 우선순위 | 기능 | 비고 |
|:---:|---|---|
| ★ | 계좌·카드 연동 | 오픈뱅킹/마이데이터 제휴 or 스크래핑. 비용·규제 부담 큼 |
| ★ | 커뮤니티 | 절약 챌린지·지출 인증. 리텐션엔 좋지만 운영 비용 큼 → MAU 확보 후 |

## 3. 수익화 설계

### 3-1. 메인 — Dayflow Pro (프리미엄 구독) ★★★

기존 시안 가격 유지: **₩3,900/월 · ₩39,000/년(월 ₩3,250, 17% 할인) · 3일 무료 체험.**
한국 유틸리티 앱 표준 범위.

**무료/Pro 경계 원칙: "기록은 무료, 인사이트·자동화·무제한은 Pro."**
기록 자체에 한도를 걸면 무료 사용자의 데이터 축적이 멈춰 전환 동력도 죽는다.

| 항목 | 무료 | Pro |
|---|---|---|
| 거래·일정·메모 기록 | 무제한 | — |
| 영수증 OCR | 월 5장 | 무제한 |
| 월간 리포트 | 웹에서 보기만 | PDF 자동 발송 + 기간 비교 |
| 예산 | 1개 | 카테고리별 무제한 |
| 알림 | 구독 결제일만 | 인사이트 푸시 전체 |
| 테마·위젯 | 기본 | 전체 + 모듈 커스터마이징 |
| 광고 | 노출 | 제거 |

**시안 카피 수정 필요 (UpgradeSheet.tsx):**

- [ ] "무제한 기록" → 기록은 무료 플랜도 무제한이므로 다른 혜택으로 교체
- [ ] "iCloud 자동 동기화" → 실제 아키텍처(Supabase)와 불일치 → "기기 간 실시간 동기화·자동 백업"

**결제 수단**: 웹 우선이므로 **토스페이먼츠 빌링(정기결제)** 권장 — 국내 카드 정기결제 + 구현 단순.
글로벌 확장 시 Stripe 병행. 앱스토어 입점 전까지 IAP 수수료 30%를 피할 수 있는 게 웹앱의 큰 이점.

### 3-2. 보조 수익원

| 우선순위 | 수익원 | 내용 |
|:---:|---|---|
| ★★★ | 금융 제휴 (CPA) | 가장 빠른 현금화. **LoanSearch + 연봉계산기가 이미 있는 게 핵심 자산.** 대출 비교 → 제휴 링크(핀다·카카오페이 대출비교 등), 연봉계산기 → 연금/보험/카드 추천. 검색 유입 페이지라 로그인 없이도 수익 발생 |
| ★★ | 디스플레이 광고 (무료 플랜) | tools(크롭·PDF)와 대시보드 하단 한정. Pro 첫 혜택이 "광고 제거"이므로 광고는 전환 장치 겸용. 가계부 화면 내 삽입은 신뢰 훼손 → 유틸리티 페이지 위주 |
| ★ | B2B 라이트 | 공유 가계부 안착 후 "팀 경비 장부"로 변형. 지금은 스키마에 household 개념 도입 시 team 으로 일반화 가능하게 옵션만 열어두기 |

### 3-3. 전환 퍼널

```
SEO 유입 (크롭 · PDF · 연봉계산기 · 대출검색, 비로그인)
  → 도구 결과 저장/기록 유도 시점에 회원가입 (Google OAuth 기구현, 마찰 최소)
  → 가계부·구독 기록 습관화 (D7 리텐션 = 인사이트 푸시)
  → Pro 트리거 노출: OCR 한도 도달 / 월간 리포트 발송일 / 광고
  → 3일 체험 → 연간 플랜 유도 (17% 할인 배지, 기존 시안대로)
```

## 4. 실행 우선순위 및 KPI

### 실행 순서 (수익까지의 거리 기준)

1. ★★★ 대출·연봉 페이지 제휴 링크 부착 — 개발 1주 내, 즉시 수익
2. ★★★ 예산 + 반복 거래 + 결제일 알림 — 리텐션 기반
3. ★★ 월간 리포트 + 영수증 OCR — Pro 핵심 가치
4. ★★ 토스페이먼츠 빌링 연동 + UpgradeSheet 실결제 wire-up
   (PC용 업그레이드 모달 신규 필요 — 현재 시트는 모바일 전용)
5. ★★ 인사이트 푸시 → 전환 퍼널 완성

### KPI

| 지표 | 목표 |
|---|---|
| 도구 페이지 → 가입 전환율 | 3~5% |
| D7 리텐션 (가계부 기록 유저 기준) | 25%+ |
| 무료 → 체험 전환율 | 5% |
| 체험 → 유료 전환율 | 40%+ (3일 체험은 짧아서 높게 나오는 편) |
| 제휴 클릭 RPM | 측정 후 베이스라인 설정 |

### 리스크

4개 축을 동시에 키우면 전부 어중간해진다. 타이머·메모·캘린더는 유지보수만,
신규 투자는 머니 축에 집중하는 것이 현재 규모에서 유일하게 작동하는 전략.
